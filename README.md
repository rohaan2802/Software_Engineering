## Course Overview

Software Engineering at FAST-NUCES Islamabad, Spring 2026. The repository has 14 lectures, four assignments with three Scrum sprint reports, the LibraryMS final project report, quizzes, class activities and exam papers, two textbooks and my study notes.

## Topics Covered

| Unit | Topics |
|---|---|
| **Unit 1 – Process** | Software engineering basics, lifecycle activities and the traditional process models. |
| **Unit 2 – Agile & requirements** | Agile, XP and Scrum, requirements engineering, user stories and specifications. |
| **Unit 3 – Testing** | Error, fault and failure, black-box and white-box testing. |
| **Unit 4 – Management & architecture** | Project management, WBS, Gantt charts, the critical path method and architectural styles. |

| Lecture | Topic | Covers |
|---|---|---|

| 04 | [Traditional models](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2304) | Waterfall, incremental, prototype, Boehm spiral and RAD models |
| 05 | [Agile models](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2305) | Agile manifesto, Extreme Programming, Scrum roles, events and backlogs |
| 06 | [Requirements engineering](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2306) | Functional and non-functional requirements, elicitation and prioritisation |
| 07 | [User stories](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2307) | User story template, acceptance criteria and the INVEST criteria |
| 08 | [Writing requirements](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2308) | Natural-language and structured specifications and the requirements document |
| 09 | [Software testing](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2309) | Error, fault and failure, test levels and structuring test cases |
| 10 | [Black-box testing](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2310) | Equivalence partitioning and boundary value analysis |
| 11 | [White-box testing](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2311) | Control flow graphs, cyclomatic complexity and path coverage |
| 12 | [Software project management](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2312) | Planning, estimation, work breakdown structure and Gantt charts |
| 13 | [Software architecture](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2313) | Architectural views and styles: pipe-and-filter, layered, client-server and MVC |
| 14 | [Critical path method](https://github.com/rohaan2802/Software_Engineering/tree/main/Lecture%20%2314) | A worked CPM example with forward and backward passes and slack |

## Using the Files

```bash
git clone https://github.com/rohaan2802/Software_Engineering.git
cd Software_Engineering
```

- Lectures are PDF and PowerPoint (`.pptx`) files; assignments, quizzes and activities are PDF and Word (`.docx`) files.
- The study notes in `Notes` are Markdown and read directly on GitHub; the CPM lecture video is an MP4.
- You can also download everything as a ZIP from the Live Links table.

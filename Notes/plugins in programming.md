# Plugins in Programming

## Plugins in Programming

Think of plugins as add-ons that give extra abilities to a program  
Simple idea:  
A plugin is like a phone app extension.  
Your main app = the program  
The plugin = something you install to add new features  
Easy example:  
Imagine a music player J  
By default, it just plays songs.  
But if you install plugins, you can:  
Add cool sound effects  
Show song lyrics  
Change the design/theme  
These extra features come from plugins, not the original program.  
In programming:  
A plugin is a separate piece of code that:  
connects to a main program  
adds new functionality  
doesn't require changing the original code much  
Real-world examples:  
Browser plugins (extensions)  
→ Ad blockers, password managers  
WordPress plugins  
→ Add contact forms, SEO tools  
Game plugins/mods  
→ Add new levels, weapons, or features  
You can customize software  
Developers don't need to build everything from scratch  
Easy to add or remove features anytime  
one-line definition:  
A plugin is a small program that adds new features to a bigger program without  
changing its core.

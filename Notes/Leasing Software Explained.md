# Leasing Software

## Leasing Software

What is “leasing software” (simple meaning)?  
Leasing software means you don’t buy the software permanently.  
Instead, you rent or subscribe to use it for a fixed time (monthly or yearly).  
Think of it like:  
Car lease = you use the car, but don’t own it  
Software lease = you use the software, but don’t own it  
So “lease” here means temporary usage rights in exchange for payment.  
Easy definition:  
Software leasing = paying regularly to use software instead of buying it forever.  
Examples of leasing software  

### 1. Microsoft 365 (Word, Excel, PowerPoint)

You pay monthly/yearly  
You use the apps online or installed  
If you stop paying → access ends  
This is leasing (subscription model)  

### 2. Adobe Photoshop / Adobe Creative Cloud

You don’t buy Photoshop permanently anymore  
You subscribe monthly  
You always get updates while subscribed  

### 3. Google Workspace (Gmail for business, Drive, Docs)

Companies “lease” it for employees  
Pay per user per month  

### 4. Canva Pro

Monthly subscription  
Access premium features while active plan exists  
What “lease” means in software context?  
In software:  
Not ownership  
Only usage rights  
⏳ Limited time access  
Can renew anytime
